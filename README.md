# THUG2 Remix decomp

A matching decompilation of **Tony Hawk's Underground 2: Remix** (PlayStation Portable (PSP), the Feb 17, 2005 prototype build (serial to be read from the image's PARAM.SFO in Phase 1)): C source that, compiled with the original
era's toolchain and linked in the original order, reproduces every shipped binary byte for byte, verified by a hash check
inside every build.

A matching decompilation of the Feb 17, 2005 prototype's BOOT.BIN (and any code modules on the image) to 100% source, byte-identical; to make the Remix-exclusive content (levels, characters and cutscenes absent from the PC version of Underground 2) readable in source; and to build PSP decompilation methods and tools that transfer to other PSP games. The US and EU retail builds follow as additional configurations.

## The no-ROM policy

Nothing derived from the game enters git — from the first commit, whether the repository is public or private. The
`.gitignore` is the firewall; `tools/audit_public.py` (its sources in `config/firewall.txt`) is the gate, run in CI on every
push; a pasted listing of the target's instructions counts too. See `docs/wiki/The-ROM-firewall.md` (TODO: created when
the wiki is set up) and `src/NOTICE.md`.

## How this project is made

This project is developed with substantial assistance from Anthropic's Claude; every match is verified by a byte-identical build, and names and public-facing text are reviewed by a person.

The standard it holds itself to: a function is "matched" only when the whole binary still hashes with it compiled from
source; names and types are evidence-based, never guessed (an address-named placeholder is honest); every outward message
to another project is written by a person; the project makes no automated requests to community services. The record —
the phase syntheses, the decision log, the cookbook of byte-proven idioms — is what makes the work auditable.
